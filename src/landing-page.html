CartoCrow is a framework that simplifies the implementation of algorithms in cartographic visualization. It allows researchers to experiment with these algorithms and use them to generate maps. The framework behind CartoCrow can be used to run other cartography algorithms online. CartoCrow consists of a C++ library which also provides a command-line frontend, and a web interface which allows end users to generate maps in a user-friendly way.

Cartographic algorithms implemented by CartoCrow:

A necklace map is a type of symbol map where the symbols are not displayed on top of each region, but rather placed as ‘beads’ on curves (‘necklaces’) surrounding the map. CartoCrow implements an algorithm to generate necklace maps automatically.

  • B. Speckmann and K. A. B. Verbeek. Necklace maps. IEEE Transactions on Visualization and Computer Graphics, 16(6):881–889, 2010.
  • B. Speckmann and K. A. B. Verbeek. Algorithms for necklace maps. International Journal of Computational Geometry and Applications, 25(1):15–36, 2015.

A chorematic map summarizes classed region maps with a single disk choreme.

SimpleSets is a spatial set visualization technique that uses simple shapes to enclose categorical point patterns.

  • S. W. van den Broek, W. Meulemans, and B. Speckmann. SimpleSets: Capturing categorical point patterns with simple shapes. IEEE Transactions on Visualization and Computer Graphics, 31(1):262–271, 2025.

CartoCrow uses CGAL, the Computational Geometry Algorithms Library, for its exact implementations of geometric algorithms.
